## Overview

A modern portfolio showcasing my projects, skills and education as a Computer Science & Engineering student and web developer, featuring a 3D character scene and smooth scroll animations.

## Tech Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **3D & Animation:** Three.js, GSAP
- **Tooling:** Git, GitHub, ESLint

## Getting Started

```bash
git clone https://github.com/rahulde2007/rahuls-3d-world.git
cd rahuls-3d-world
npm install
npm run dev
```

| Command           | Description              |
| ----------------- | ------------------------ |
| `npm run build`   | Production build         |
| `npm run preview` | Preview the build        |
| `npm run lint`    | Run ESLint               |
